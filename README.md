# Auto-Populated Repair Documentation

This project analyzes a real-world repair documentation process and proposes a minor system improvement to reduce repetitive manual data entry.

The proposed change allows part numbers already recorded in the Part Lookup system to automatically populate in the Failure and Defect section.

## Tools Used

- Confluence — business problem, objective, scope, and functional requirements
- Miro — AS-IS and TO-BE process diagrams
- Jira — user story and acceptance criteria
